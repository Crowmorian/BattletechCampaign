# Indirect Fire

A concise reference for how indirect fire works and how to calculate the final target number.

## 1. What you need

| Requirement | Rule |
| --- | --- |
| Indirect-capable unit | The firing unit must have an **IF#** special (for example, IF1, IF2, IF3). |
| Spotter | A friendly unit must have **line of sight** to the target. The firing unit itself does **not** need line of sight. |
| Range | The target must be within the **firing unit’s** range. The spotter does not extend weapon range. |
| Damage | If the attack hits, it deals the firing unit’s **IF** value, not its normal S / M / L damage. |

## 2. Quick rule summary

| Step | What happens |
| --- | --- |
| 1 | Choose a firing unit with **IF#**. |
| 2 | Choose a friendly spotter that has line of sight to the target. |
| 3 | Measure range from the **firing unit** to the target. |
| 4 | Work out the target number using the formula below. |
| 5 | If the attack hits, deal the unit’s **IF** damage. |
| 6 | A spotter may designate **one target** that turn; multiple friendly IF units may fire at that same spotted target. |
| 7 | If the spotter also attacks, indirect fire is harder: use an extra **+1 penalty** (so indirect becomes **+2 total** instead of +1). |

## 3. Final to-hit formula

**Target Number = Skill + Range Modifier + Target TMM + Terrain / Cover + Indirect Fire Modifier + Other Situational Modifiers**

| Part | Use this |
| --- | --- |
| Skill | The firing unit’s Skill value. |
| Range Modifier | Based on the range from the **firing unit** to the target. |
| Target TMM | The target’s current Target Movement Modifier. |
| Terrain / Cover | Apply terrain and cover based on the **spotter’s line of sight** to the target. |
| Indirect Fire Modifier | **+1** normally. If the spotter also attacks, use **+2 total** instead. |
| Other Situational Modifiers | Any other normal scenario, special ability, or command modifiers that apply. |

## 4. Mini example

**Archer (Skill 4, IF2)** fires indirectly at long range. The target has **TMM +2** and **light cover +1** from the spotter’s view. The spotter is only spotting, so the indirect penalty is **+1**.

**Final Target Number = 4 + 4 + 2 + 1 + 1 = 12**

If it hits, the Archer deals **2 damage** (because it has IF2).

## 5. Handy reminders

- Use the **IF** value, not normal S / M / L damage.
- The **spotter gives visibility**; it does not extend range.
- The firing unit can stay hidden behind terrain as long as the spotter can see the target.
- Fast scouts such as a Locust, Mercury, or Fire Moth make excellent spotters.
- Indirect fire is strongest for punishing hidden or slow targets, not for chasing high-TMM skirmishers.
